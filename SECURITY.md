# Security

Please report vulnerabilities privately with GitHub's **Report a vulnerability** button on the repository's Security tab. Don't open a public issue.

The design's security model is in [docs/design/architecture.md](docs/design/architecture.md#security-model). The release-signing scheme is in [docs/design/updates-and-releases.md](docs/design/updates-and-releases.md#signing).

Until 1.0, only the latest release gets fixes.
