# Contributing

Couchbox is in its planning stage ([docs/PLAN.md](docs/PLAN.md)). Issues and discussion are welcome now. Code contributions open with milestone M1.

- **Commits and PR titles** follow [Conventional Commits](https://www.conventionalcommits.org) (`feat:`, `fix:`, `docs:`…). PRs are squash-merged, and release-please builds the changelog from them.
- **Sign off** your commits (`git commit -s`, the [DCO](https://developercertificate.org)). Contributions are accepted under the Apache-2.0 license.
- **Tests:** every change comes with tests ([docs/design/ci-and-testing.md](docs/design/ci-and-testing.md)). UI changes include updated screenshots.
- **No personal values:** never commit host names, tailnet names, API keys, cookies or account details. CI checks for them.
